# Neonatal Jaundice Detection Using Machine Learning

A non-invasive diagnostic system for early detection of neonatal jaundice using facial image analysis and machine learning, developed by Dr. Yasir Hussein Shakir.

![Project Banner](https://res.cloudinary.com/tbmg/c_scale,w_800,f_auto,q_auto/v1552709066/sites/mdb/articles/2014/features/20594_fig1.png)



## 📋 Overview

This project implements a non-invasive diagnostic method for neonatal jaundice using image processing and machine learning. The system analyzes facial images of newborns aged 2 to 8 days with varied skin tones and birth weights, extracting color features from RGB and YCrCb channels to provide accurate, real-time detection without invasive blood tests.

## 🚀 Features

- Non-invasive diagnosis using facial images
- Color feature extraction from RGB and YCrCb channels
- SVMSMOTE handling for class imbalance
- Eight machine learning classifiers and ensemble methods
- High accuracy (99.35%) for early jaundice detection
- Public NJN dataset via Zenodo for research
